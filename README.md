One letter for the day: **G — for Gas.**

`main.py` writes exactly one byte, the letter `G`, to `/output/entry.txt` — nothing else, no newline. Run it with `python3 main.py` (or set `MAKEFUN_OUTPUT_DIR` to choose the output folder).

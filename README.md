G for Gas: one letter for my day. The program writes exactly the single letter `G` — and nothing else — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

This writes `/output/entry.txt` containing exactly `G`, with no trailing newline.

## Files

- `main.py` — entrypoint: writes the single letter to `/output/entry.txt`.
